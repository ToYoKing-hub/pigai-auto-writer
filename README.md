# 批改网自动写作工具 (Pigai.org Auto Writer)

> 基于 Playwright + LongCat API 的英语作文自动写作 & 刷分工具，支持图形化界面。

## 功能

- **自动登录** — 自动登录批改网，完善个人信息，加入班级
- **多模型切换** — 支持 LongCat / DeepSeek / 通义千问 / 智谱 GLM / Moonshot / OpenAI 等，Web UI 一键切换
- **自动写作** — 根据作文题目要求，调用 LLM API 生成高质量英语作文
- **自动提交** — 模拟键盘输入绕过粘贴限制，自动提交作文
- **刷分模式** — 读取教师点评 → 针对性修改原文 → 重提交，循环直到达标
- **字数控制** — 严格确保作文字数在题目要求范围内
- **图形化界面** — Web UI 配置所有参数，实时查看运行日志和分数

## 安装

### 1. 安装依赖

```bash
pip install playwright anthropic flask
playwright install chromium
```

或使用 `requirements.txt`:

```bash
pip install -r requirements.txt
playwright install chromium
```

### 2. 配置

编辑 `server.py` 中的 `DEFAULT_CONFIG` 或在 Web UI 中填写：

```python
{
    "username": "你的批改网手机号",
    "password": "你的批改网密码",
    "rid": "作文号",
    "api": {
        "key": " API Key",
        "model": ""
    }
}
```

### 3. 运行

```bash
python server.py
```

浏览器打开 `http://localhost:5000`

## 使用方法

1. **修改作文号** — 输入批改网上的作文号 (rid)
2. **填写配置** — 账号、个人信息、班级信息、API Key
3. **执行选项** — 设置是否跳过个人信息/班级、是否开启刷分模式
4. **开始运行** — 点击按钮，等待自动完成

### 执行选项说明

| 选项 | 说明 |
|------|------|
| 跳过个人信息 | 已填写过请开启，首次使用请关闭 |
| 跳过加入班级 | 已加入过请开启，首次使用请关闭 |
| 刷分模式 | 开启后反复修改提交，直到达到目标分数 |

### 刷分流程

```
第1次: 生成作文 → 提交 → 查分 → 读教师点评
第2次: 根据点评修改原文 → 重提交 → 查分 → 读点评
第3次: 继续修改 → 重提交 → 查分
...
直到达到目标分数或达到最大尝试次数 (10次)
```

## 技术架构

```
┌─────────────────────────────────────────────┐
│                  Web UI                      │
│         (templates/index.html)               │
├─────────────────────────────────────────────┤
│              Flask Server                    │
│            (server.py)                       │
│  - 配置管理 / 运行控制 / 状态轮询            │
├─────────────────────────────────────────────┤
│           PigaiAutomator                     │
│          (pigai_auto.py)                     │
│  ┌─────────┐  ┌──────────┐  ┌─────────────┐ │
│  │ 登录    │  │ 获取要求 │  │ 撰写作文    │ │
│  │ Login   │→ │ Get Req  │→ │ Write Essay │ │
│  └─────────┘  └──────────┘  └─────────────┘ │
│  ┌─────────┐  ┌──────────┐  ┌─────────────┐ │
│  │ 提交    │  │ 查分数   │  │ 读点评      │ │
│  │ Submit  │→ │ Check    │→ │ Get Review  │ │
│  └─────────┘  └──────────┘  └─────────────┘ │
│                    ↓                         │
│             刷分循环 (Modify → Submit → Loop) │
├─────────────────────────────────────────────┤
│   Playwright (浏览器)  │  LongCat API (AI)   │
└─────────────────────────────────────────────┘
```

### 核心流程

1. **登录** → 自动填写账号密码，点击登录按钮
2. **获取要求** → 解析作文页面，提取题目、字数要求
3. **撰写作文** → 优先使用预设模板，否则调用 LLM API 生成（支持多家模型）
4. **提交** → 逐字模拟键盘输入（绕过粘贴限制），处理确认弹窗
5. **查分** → 从页面元素精确提取自己的分数
6. **刷分** → 读取教师点评 → 根据点评修改原文 → 重提交 → 循环

### 关键技术点

- **绕过粘贴限制**: 使用 `page.type()` 逐字符模拟键盘输入
- **精确分数提取**: 从 `.circles-integer` + `.circled-decimals` 元素读取，避免与排行榜最高分混淆
- **重复提交检测**: 检测页面错误提示，自动重写完全不同的作文
- **字数控制**: 生成后验证字数，不符则重新生成（最多3次）
- **点评驱动改进**: 将教师评语、错误类型、改进建议全部传给 API

## 注意事项

- 本工具仅供学习交流使用

- LLM API 按 token 计费，刷分模式会消耗更多 token
